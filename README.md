# SBPele

A pure [Space Lua](https://silverbullet.md) library that adds [Pele](https://pele.run/) Mermaid-compatible diagrams to [SilverBullet](https://silverbullet.md).

It provides live `pele` and `mermaid` fenced blocks plus a `sbpele` API for dynamic diagrams generated from page data. Diagrams use a high-contrast palette that stays visible in both light and dark themes.

## Installation

Install `SBPele.md` through SilverBullet's Library Manager:

```text
github:jasinco/SBPele/SBPele.md
```

Pele is loaded from jsDelivr by default. See the library page for configuration and the offline/self-hosted bundle option.
